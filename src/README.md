# 🧠 Dashboard UI

A clean and minimal dashboard interface with customizable themes, combining productivity tools and ambient experience.

## ✨ Features

- 🕒 Analog + Digital clock with dynamic background typography  
- 📅 Compact calendar with background month label  
- 🎵 Lo-fi vinyl player with smooth rotation
- ✅ Task management (To Do / Doing / Done)  
- 🎨 Multiple color themes  
- ⚙️ Settings modal  
- 📱 Responsive layout (optimized for tablets)
